Problem 1: Check Whether a Given Positive Integer Is Prime

Write a C program that uses a function to determine whether a given positive integer is prime.

Approach:
Create a function isPrime() that checks whether the given number has any divisor other than 1 and itself.

Time Complexity: O(sqrt(n))
Space Complexity: O(1)

C Program:

#include <stdio.h>

int isPrime(int n)
{
    if (n < 2)
        return 0;

    for (int i = 2; i * i <= n; i++)
    {
        if (n % i == 0)
            return 0;
    }

    return 1;
}

int main()
{
    int n;

    printf("Enter a positive integer: ");
    scanf("%d", &n);

    if (isPrime(n))
        printf("%d is a prime number.\n", n);
    else
        printf("%d is not a prime number.\n", n);

    return 0;
}
